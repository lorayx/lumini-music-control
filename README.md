# LUMINI Music Control

Музыка прямо на панели задач Windows 11.

![Панель LUMINI во время воспроизведения](docs/taskbar-preview.png)

A lightweight Windows 11 taskbar music controller with cover-colour, audio-reactive liquid glow.

## Что умеет

- Обложка, название и исполнитель на прозрачной панели рядом с погодой.
- Предыдущий трек, воспроизведение/пауза и следующий трек.
- Перемотка: наведите курсор на название и исполнителя.
- Сердечко для «Мне нравится» в Яндекс Музыке.
- Жидкое свечение в цветах обложки: кик, бас и мягкое движение от других частот.
- До 30 кадров/с, поддержка уменьшения анимации, настройки и значок в трее.
- Запуск выбранного плеера по нажатию Play, если это включено в настройках.
- Настоящая очередь Яндекс Музыки вместо второго плеера: выбор подготовленного трека и кнопка «Моя волна».

## Скачать и установить

Откройте [Releases](https://github.com/lorayx/lumini-music-control/releases) и выберите выпуск **v0.12.0**:

- `LUMINI-Music-Control-0.12.0-windows-x64-setup.exe` — обычная установка для текущего пользователя.
- `LUMINI-Music-Control-0.12.0-windows-x64.zip` — архив с программой.

Нужны Windows 11 x64 и Microsoft Edge WebView2 Runtime. Для полной функциональности — установленная Яндекс Музыка с выполненным входом в аккаунт. Один раз выполните вход в Яндекс Музыке. Затем откройте LUMINI и нажмите Play; запуск приложения по Play можно включить в настройках. Панель появится на панели задач; настройки доступны через значок в трее.

Сборка пока не имеет цифровой подписи издателя. Файлы проверяются по `SHA256SUMS.txt` соответствующего релиза.

## Совместимость и ограничения

Основные проверки выполнены с настольной Яндекс Музыкой на Windows 11 x64 с русским интерфейсом. Для других приложений доступность управления зависит от их поддержки Windows Media Session; реакция на звук и специальные команды сейчас ориентированы на Яндекс Музыку.

- Это самостоятельное приложение поверх панели задач, а не модификация Explorer.
- Полностью незаметный запуск музыкального приложения не гарантируется: окно может кратко появиться.
- Кнопка текста песни показывается при доступной команде и открывает текст в Яндекс Музыке. Построчного текста внутри LUMINI пока нет.
- Доступность сердечка и текста зависит от интерфейса Яндекс Музыки. При неизвестном состоянии первое нажатие сердечка только добавляет трек.
- Детектор анализирует общий музыкальный микс: отдельные замаскированные удары могут пропускаться, а басовые ноты иногда воспринимаются как кик.
- Автоскрытие панели задач, нестандартные оболочки и все сочетания мониторов не проверены.

## Приватность

LUMINI получает данные трека из медиасессии Windows. Реакция на музыку анализируется локально через WASAPI process loopback только для процесса Яндекс Музыки и его дочерних процессов. Микрофон не используется, аудиозапись не сохраняется и звук не отправляется на сервер. Данные аккаунта Яндекса приложению не нужны. Программа хранит настройки и локальные диагностические сообщения; перед публикацией отчёта проверьте его содержимое.

## Сборка из исходников

Инструменты: Node.js 22.12+ с npm, Rust 1.90+ с целью `x86_64-pc-windows-msvc`, Microsoft C++ Build Tools с Desktop development with C++ и Windows SDK.

```powershell
npm ci
npm test
npm run build
./scripts/Build-Windows.ps1 -Mode test
./scripts/Build-Windows.ps1 -Mode bundle
```

Установщик будет в `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/` либо в каталоге, заданном `CARGO_TARGET_DIR`.

Интерфейс: React, TypeScript, Tauri 2. Нативная часть: Rust и Windows API. Обработка звука: лёгкий фильтробанк с обновлением каждые 10 мс и независимыми огибающими для анимации.

## Новое в 0.12.0

Play ожидает подтверждения воспроизведения, повторяет ещё не принятые команды и использует резервную кнопку приложения, если системная команда не сработала. Краткое исчезновение медиасессии при смене трека больше не приводит к немедленному отказу команды.

Нажатие обложки на панели задач открывает настоящую очередь треков. Выберите строку для воспроизведения или нажмите «Моя волна». Показаны только подготовленные приложением записи (до 50), а не вся библиотека аккаунта. Для чтения списка LUMINI может перейти к Коллекции и открыть экран очереди в Яндекс Музыке. Кнопка обновления получает актуальный список; устаревший список не используется для выбора трека.

![Очередь треков и Моя волна](docs/queue-preview.png)

При запуске Яндекс Музыки включается документированный режим доступности Chromium (`--force-renderer-accessibility=complete`). Фоновые команды не запрашивают фокус и восстанавливают свёрнутое или скрытое состояние окна. При холодном запуске Яндекс Музыка всё ещё может кратко показать своё окно. Наличие сети, входа в аккаунт и подписки проверяется в самом музыкальном приложении.

Очередь и дополнительные действия рассчитаны на русский интерфейс Яндекс Музыки в стандартной папке установки. Изменения её интерфейса после обновления могут потребовать адаптации LUMINI.
