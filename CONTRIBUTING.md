# Как помочь

Обсуждения, отчёты об ошибках и предложения приветствуются. Для заметных изменений сначала создайте Issue, чтобы согласовать поведение.

Перед PR выполните `npm test`, `npm run build` и `./scripts/Build-Windows.ps1 -Mode test`. Для Windows-функций опишите фактически проверенную систему. Не включайте node_modules, установщики, записи звука, личные настройки и диагностические отчёты своего аккаунта в коммит.

Разработка ориентирована на локальную обработку звука, ненавязчивый интерфейс и самостоятельное приложение без внедрения в Explorer.
