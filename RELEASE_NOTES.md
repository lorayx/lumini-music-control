# LUMINI Music Control 0.11.0

Первый публичный выпуск для Windows 11 x64.

Компактный плеер прямо на панели задач: управление музыкой, перемотка по наведению, сердечко и живое свечение в цветах обложки. Новая реакция учитывает кик, глубокий бас, середину и высокие частоты; чувствительность подстраивается под запись. Отрисовка — до 30 кадров/с.

Установщик: `LUMINI-Music-Control-0.11.0-windows-x64-setup.exe`.
Архив программы: `LUMINI-Music-Control-0.11.0-windows-x64.zip`.

Полная функциональность ориентирована на настольную Яндекс Музыку. В приложении должен быть выполнен вход и доступен трек. Требуется WebView2 Runtime. Установщик пока без цифровой подписи. Основные ограничения перечислены в README.

Микрофон, запись звука и внешние сервисы анализа музыки не используются.
